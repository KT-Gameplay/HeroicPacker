# Sprite optimizer input

Put sprite PNG files and their matching atlas metadata inside this folder.

Examples:
- `characters/bf.png`
- `characters/bf.xml`
- `stages/example.png`
- `stages/example.json`

Keep each metadata file beside its matching PNG and use the same base filename.

Do not put Heroic Packer source files here. Every push that changes files in this folder
(except this README) starts the optimizer.
